# Отчёт по практическим занятиям 13–17

## Практическое занятие 13: Service Worker

Подготовлено приложение «Заметки» на React с регистрацией Service Worker и стратегиями кэширования.

### Реализовано

- Регистрация Service Worker.
- Кэширование статики через Service Worker.
- Сохранение заметок в LocalStorage.

## Практическое занятие 14: Web App Manifest

Доработан манифест для более эффективной стратегии работы приложения как PWA.

### Реализовано

- Манифест PWA (`manifest.json`, иконки) для установки приложения как прогрессивного веб-приложения.
- Кэширование иконок и манифеста через Service Worker.
- Загрузка HTML-фрагментов страниц в приложение (`content/*.html`).

## Практическое занятие 15: HTTPS + App Shell

Настроена серверная и клиентская часть push-уведомлений по стандарту Web Push.

### Реализовано

- Создание сертификатов и запуск сайта через HTTPS.
- Использование Cache Storage для сохранение статики.

## Практическое занятие 16: WebSocket + Push

Реализован механизм уведомления о задачах через пуши и веб сокеты

### Реализовано

- Express-сервер для поддержания соединения для информирования о новых заметках.
- Созданы vapid-ключи для обеспечения безопасного подключения веб-сокетов.
- Визуальное уведомление о создании задачи.
- Уведомление о создании задачи через пуш.

## Практическое занятие 17: Детализация Push

Доработано приложение: планирование напоминаний и действие «Отложить в Service Worker.

### Реализовано

- Форма отложенной отправки уведомления.
- Отложенная отправка уведомления через таймаут.
- Функция откладывания уведомления через snooze.
